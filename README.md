# تُحفة — عناصر فاخرة ذكية لمتاجر سلة

مجموعة من 7 عناصر (Twilight Component Bundle) لأي ثيم في سلة:

| العنصر | الوصف |
|---|---|
| `salla-tuhfa-hero` | سلايدر سينمائي: تقريب، تلاشٍ، شريط تقدم، سحب على الجوال |
| `salla-tuhfa-smart-products` | منتجات بشارات ذكية تلقائية (خصم، آخر القطع، الأعلى تقييماً، الأوفر) |
| `salla-tuhfa-countdown` | بانر عرض بعدّاد حي وكوبون بنقرة نسخ، ويختفي بعد انتهاء العرض |
| `salla-tuhfa-numbers` | أرقام حيّة تعدّ عند الظهور |
| `salla-tuhfa-compare` | مقارنة 2–4 منتجات مع ترشيح «الاختيار الذكي» |
| `salla-tuhfa-reviews` | شريط آراء متحرك ومتوسط تقييم وشارات ثقة |
| `salla-tuhfa-categories` | شبكة أقسام تحريرية غير متماثلة |

```bash
pnpm install
pnpm run build   # dist/<component>.js
pnpm run dev     # معاينة محلية
```
